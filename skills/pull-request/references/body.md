# Default pull request body

Omit a section that has nothing to say instead of writing "N/A".

```markdown
## What
The change in a few bullets, from the reader's point of view.

## Why
The problem or request it answers.

## Verification
Each command that ran with its exact summary line, then what was not verified.

## Risk and rollback
Only for high-risk or compatibility-breaking changes: what must keep working and how to undo the change.

## Open warnings
Review findings left open, one line each with file and line.
```
